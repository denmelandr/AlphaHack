# Backend кредитного конвейера

Этот каталог сохранён как backend-часть объединённого проекта. Прежний frontend удалён по запросу владельца; единственный интерфейс теперь находится в `../src`.

Канонические запуск, демо-аккаунты и ограничения: [корневой README](../README.md).

```sh
cd ..
docker compose up --build -d
```

Сайт — http://localhost:5173, Swagger — http://localhost:8080/docs.

Вложенный `docker-compose.yml` включает корневой Compose. Миграции, исходные моки, тесты и документы сохранены. Отчёт `docs/audit-2026-10-26/REPORT.md` относится к предыдущей сборке; выявленные там критические ошибки закрываются в корневом `docs/integration-matrix.md` и регрессионных API-тестах.
