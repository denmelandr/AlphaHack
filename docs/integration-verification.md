# Проверка объединённого кабинета — 26.10.2026

## Сборка и запуск

- `docker compose up -d --build`: собраны и запущены наш frontend (nginx), FastAPI, PostgreSQL 16, Redis 7, integrations-mock.
- Backend, БД, Redis и моки имеют healthy; сайт публикуется на localhost:5173, API на localhost:8080.
- Корневой и вложенный Compose прошли `config --quiet`.
- Миграция Alembic сохранена и применяется при старте. БД и файлы вынесены в pgdata/ uploads.
- Production-сборка React/TypeScript прошла внутри Docker. Есть некритичное предупреждение Vite о размере JS-чанка; виртуальные `use client` библиотек игнорируются Vite.
- Второй frontend отсутствует в дереве проекта и не участвует в сборке.

## Автоматические проверки

- **35 backend-тестов пройдены**: 25 исходных проверок доменных движков и 10 новых регрессионных API-тестов на настоящем PostgreSQL с откатом данных после каждого теста.
- API-регрессии покрывают серверный вход, фильтрацию компаний, запрет клиенту политик, регистрацию, невозможность самоназначить банковскую роль, CRUD черновика и восстановление, документы/readiness/submit, what-if/сохранение условий, ручное решение с новым оффером, запрет банковского принятия оффера, применение/повтор действий, изменение ликвидности и дебиторки, портфель, автопилот с нулевым лимитом, YAML/версии/права, совместное согласование и загрузку/скачивание/изоляцию файлов.
- **23 frontend unit-проверки пройдены**: финансовые расчёты, сохранённые функции прежнего прототипа и новый транспорт авторизации/ограничения ролей. Они не заменяют браузерную проверку интерфейса.
- Актуальная OpenAPI сохранена в `docs/openapi.json` (39 путей).

## Проверка в браузере

Серверный демо-вход через наш интерфейс, список компаний с именами/ИНН, выбор Весны и Ромашки, радар/счета/рискованный должник/варианты/автопилот/награды, YAML и shadow просмотрены на localhost:5173. Через интерфейс создан и сохранён серверный черновик, проверен переход между шагами. Банковский портфель отображает серверные ковенанты и метрики. Мобильный экран 390px проверен: горизонтального переполнения страницы нет; шрифты и плоский выбор компании сохранены. Консоль браузера в итоговой production-версии без ошибок. Подпись и деньги — исключительно синтетические. Изменения политики в ходе браузерной проверки не активируются, чтобы сохранить исходный демонстрационный сценарий.

## Границы проверки

Тесты и экраны используют синтетическую БД и моки, а не внешние банковские системы. ПЭП, фактические перечисления и сообщения не выполняются. Отправка приглашений участников и интеграции 1С/Ozon/WB не реализованы. В шаблонном режиме LLM не вызывается. Метрики просрочки и дохода — подписанные в интерфейсе модельные оценки. Для production нужны меры из `credit-conveyor/docs/SECURITY.md`, серверный отзыв сессий, SSO/MFA, защищённое объектное хранилище и проверка файлов.
